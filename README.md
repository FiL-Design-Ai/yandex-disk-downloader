# Яндекс.Диск: скачивание по ссылке (Chrome)

Версия 2.0.0. Расширение скачивает файлы и папки с **публичной** ссылки Яндекс.Диска (`disk.yandex.ru/d/...` или `yadi.sk/d/...`). Приватные файлы без ссылки не поддерживаются.

## Что умеет

- **Кнопка «Скачать»** в правом нижнем углу каждой публичной папки или файла на Яндекс.Диске. Видна всегда. Во время загрузки показывает процент, после окончания «Готово ✓».
- **Окно загрузки** открывается по кнопке, по Alt+Shift+D или по пункту «Скачать с Яндекс.Диска» в меню правой кнопки на ссылке. Окно маленькое, отдельное, не вкладка. Пока окно открыто, кнопка на странице показывает прогресс. Если закрыть окно во время загрузки, загрузка остановится, и Chrome спросит подтверждение.
- **Окно плагина** (иконка в панели Chrome): вставить ссылку, нажать «Показать файлы». В окне загрузки есть недавние ссылки (до 5).
- **Список файлов:** галочки, «Выбрать все», под списком видно, сколько выбрано и примерный объём. По умолчанию ничего не выбрано.
- **Выбор папки:** Chrome спросит папку на компьютере. Внутри неё плагин создаёт папку с названием из Яндекс.Диска (например, `Дуся_v2`) и повторяет структуру.
- **Без повторной загрузки:** если файл уже есть и совпадает с Яндекс.Диском (по SHA-256, а если хеша нет, то по размеру), он пропускается. Если отличается, заменяется новым.
- **Докачка:** если загрузка оборвалась или её остановили, частично скачанный файл сохраняется, и следующая попытка качает только остаток. Итоговая проверка SHA-256 проверяет весь файл.
- **Повторы при сбоях:** на каждый файл до 5 попыток. Во время повторов видно номер попытки. Если что-то не скачалось, в конце показываются имя файла и причина.
- **Отчёт:** в папке со скачанным лежит файл `download-report.txt`: что записано, что уже было, что не скачалось, и SHA-256 каждого файла.
- **Остановка:** кнопка «Остановить» во время загрузки. Уже скачанные файлы остаются.
- **Запоминание папки:** после первого выбора папка запоминается, появляется кнопка «Скачать в «имя папки»». Chrome может снова спросить разрешение на запись.

## Ограничения

- Окно загрузки отдельное, а не внутри страницы Яндекса. Яндекс не разрешает встраивать чужие страницы внутрь себя.
- Запись идёт в папку, которую вы выбрали. Нужна современная версия Chrome с поддержкой выбора папки.
- Если Яндекс.Диск показывает баннер «Восстанавливаем работу сервиса», часть файлов может не скачаться. Тогда плагин покажет их в списке ошибок.
- Кнопка на странице работает на адресах `/d/`. Если Яндекс поменяет вёрстку, это почти не скажется: кнопка не зависит от его разметки.
- Автоматических тестов в проекте нет, проверка ручная (см. ниже).

## Установка

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика» (переключатель в правом верхнем углу).
3. Нажмите «Загрузить распакованное» и выберите папку с этим проектом (ту, где лежит `manifest.json`).
4. После изменений файлов нажимайте «Обновить» у плагина и перезагрузите страницу Яндекс.Диска.

## Проверка

1. Откройте `https://disk.yandex.ru/d/8UQF86iWr4Prpw`. В правом нижнем углу должна быть тёмная кнопка «Скачать».
2. Нажмите «Скачать». Откроется маленькое окно со списком файлов, все галочки сняты.
3. Отметьте один файл, например `2-Ассистент Дуся/Ассистент+Дуся_2.2.1_no_services.apk` (15 374 422 байта), и нажмите «Выбрать папку и скачать».
4. Проверьте, что кнопка на странице показала проценты, потом «Готово ✓».
5. Проверьте размер файла в выбранной папке, внутри `Дуся_v2\2-Ассистент Дуся\`, и файл `download-report.txt` рядом с ним.
6. Проверьте меню правой кнопки: на ссылке Яндекс.Диска должен быть пункт «Скачать с Яндекс.Диска».

## Файлы

- `manifest.json` — настройки расширения
- `background.js` — открывает окно загрузки, пункт меню, передаёт статус на страницу Яндекса
- `content.js` — кнопка «Скачать» на странице Яндекс.Диска
- `popup.html`, `popup.js` — окно плагина с иконки
- `download.html`, `download.js` — окно загрузки: список, выбор папки, запись файлов, отчёт
- `yandex-api.js` — общий код работы с API Яндекс.Диска
- `icons/` — иконки
